# ADR 0002：可视化优先与持续起搏

- 状态：已接受
- 日期：2026-08-18

## 背景

Gate 0～2 已能确定性运行 100～300 神经元网络，并输出放电率、同步性和轨迹差异。但汇总指标无法充分展示传播路线、局部活动、空间抑制和时间结构，继续直接叠加模型机制会增加盲目性。

当前冻结网络依赖持续起搏。撤除起搏后沉默此前容易被理解为未达到正常运行要求，但神经活动本身需要持续驱动和能量供应，持续存在的内部节律源是合理模型选择。

## 决定

- Gate 3 优先实现 3D 游览、时间回放和局部检查，不继续扩展生物机制；
- 可视化是选择后续研究方向的主要交互工具；
- 数值指标仍是验证视觉猜想的必要证据；
- 持续起搏是合法且预期的正常运行条件；
- 撤除起搏只作为依赖性诊断和消融实验；
- 起搏必须存在于模拟时间和事件日志中，不能使用影响确定性的操作系统定时线程；
- 当前起搏实现保持显式周期事件源，未来可升级为具有能量、疲劳和自主去极化状态的模拟实体；
- 能量模型在完成 Gate 3 前不实现，但播放数据契约为其预留扩展位置。

## 后果

- `drive-dependent` 不再被视为项目失败，只描述网络对持续节律源的依赖；
- `experiment-001/v1` 的撤除结果继续作为冻结回归事实，而不是未来模型必须满足的方向性要求；
- 下一项主要工程工作是只读播放数据契约和桌面可视化骨架；
- 后续是否研究真正无驱动持续、能量约束、学习或结构生长，将由可视化观察和干预结果决定。

## 非目标

- 本决策不声称当前周期事件源已经等价于真实心脏或神经起搏细胞；
- 本决策不取消撤除、断能或起搏消融实验；
- 本决策不允许动画替代统计和因果验证；
- 本决策不授权在 Gate 3 中加入能量、代谢或复杂细胞模型。
