# ADR 0004：行为优先的具身学习

## 状态

已接受。取代 ADR 0002 的“可视化优先”和 ADR 0003 的随机网络多尺度观察主路径。

## 背景

Phase 2 证明固定随机 LIF 网络可以携带输入信息，但相同输入轨迹不稳定、连接置乱后仍可读、候选功能群消融没有跨结构种子因果效应。逐神经元和逐脉冲画面无法提供缺失的功能含义。

## 决策

- 项目输出改为主体动作及其环境后果；
- 主体必须具有内部需要、有限感觉和执行器；
- 学习必须造成持久状态变化并改善未见环境行为；
- Web 改为世界、行为、内部状态和对照证据仪表盘；
- 删除 Phase 2 分类管线、3D 回放主界面、Three.js 和大体积播放数据；
- LIF 和事件网络作为底层资产保留，但不再被当作缩小版人脑。

## 后果

- 当前研究问题可以由食物、能量、存活和动作直接测量；
- 学习关闭、连接置乱和内部消融提供因果边界；
- 未来生物机制只能逐项加入闭环，并以行为或适应能力改善验收；
- Git 历史和 Phase 2 最终报告保留旧路线及负结果。
