# ADR 0005：以宏观功能形成和稳定可学习性为研究主线

## 状态

已接受。扩展 ADR 0004 的行为优先原则；具身闭环继续作为主要实验环境，但单个行为 Gate 不再等同于整体研究进展。

## 背景

Gate A～F 已分别验证奖励审计、状态记忆、延迟信用、循环结构、LIF 对照和内部可塑性。Gate F 也暴露了当前边界：二元规则、强制探索、全局后果信号和预对齐通路可能让单项适应成立，却不能证明系统可以稳定学习多种能力。

继续逐项增加任务容易得到一组人工调好的专用控制器，也无法回答我们真正关心的问题：功能是否能在有自由度的动态系统中重复形成，以及稳定、可塑、遗忘和发散之间的边界在哪里。

## 决策

- 项目总问题改为“宏观功能在什么条件下形成、保持、迁移或崩溃”；
- 采用灰盒方法：外层测绘参数到宏观结果，内层用消融、置乱和机制关闭建立因果解释；
- 不要求不同种子产生相同微观结构，但要求统计上可重复的宏观能力和中观性质；
- 下一阶段先绘制稳定可学习性地图，Gate G 改为地图阶段之后的条件分支；
- 使用固定多任务探针组，同一底层配置不得逐任务调参；
- “混沌”“涌现”“类脑”等表述必须有独立测量支持，不能从复杂可视化推断；
- 单点高分、外部可解码性和重新学习不分别等同于稳定区域、主体功能和记忆保留。

## 后果

- 近期工作将优先增加实验编排、相图统计、稳定性测量和确认性种子，而不是增加节点数量；
- Web 的主要新视图应是参数区域、功能形成概率和因果对照，逐节点动画只用于下钻解释；
- 如果不存在跨任务的稳定可学习区，项目会把它记录为负结果并修改局部规则，不直接升级任务复杂度；
- 若找到可重复区域，再以多规则保留、迁移和更自然输入检验其外推能力。
