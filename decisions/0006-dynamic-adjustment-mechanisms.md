# ADR 0006：以动态调整机制而非完备神经元为主要研究变量

## 状态

已接受。延续 ADR 0005 的宏观功能形成主线，并重新安排 Map 2 之后的工作优先级。

## 背景

项目无法先定义一个可验证的“完整神经元基座”。增加生物细节不自动产生功能，也容易让节点模型复杂度替代行为证据。Gate A～F 和 Map 0～2 的实际证据主要来自状态、资格迹、连接更新、内稳态和资源等调整机制，而不是神经元形态真实性。

Map 2C 已证明当前组合能在受控二元规则流中持续适应，但尚未证明多个能力可以保留、迁移或通过同一机制形成。此时直接扩大节点数量可能只放大一个任务特化的调整器。

## 决策

- 当前 24 单元 Map 2 系统冻结为参考载体，不称为完备或真实神经元；
- 主要研究对象改为受约束的在线调整机制及其组合；
- 机制必须局部、有界、任务无关，并接受预算匹配和因果关闭对照；
- 下一阶段先测当前机制的多规则保留边界，不先增加新机制；
- 只有失败类型明确后，才单独测试元可塑性、局部调制或结构调整；
- 机制通过后必须重新测绘连续有效区域，并以未见任务检验迁移；
- Scale 0 后移到调整机制形成连续稳定区域并至少确认一种未见条件迁移之后；
- 神经元细节只有在指标定位到具体功能缺口时，才能作为单机制候选加入。

## 后果

- 项目不再以节点功能列表的增加衡量进度；
- 新实验优先报告适应、保留、重现、迁移、稳定、鲁棒和成本组成的能力向量；
- Gate G 的多规则保留问题吸收到动态调整机制计划的 M1，不再作为自动解锁的独立功能升级；
- Scale 0 的机制前置条件虽然由 Map 2 满足，但研究优先级后移，避免扩容掩盖覆盖性遗忘或信用路由问题；
- 允许当前参考载体最终被证明不足，但必须由明确能力缺口和配对机制实验得出，而不是从“看起来不够像神经元”推断。
