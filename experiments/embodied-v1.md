# Embodied Learning v1

> 结论：通过工程验收。学习后主体在未见地图中显著优于关闭学习对照；打乱动作突触和消融重要内部单元都会破坏行为。

## 复现

```powershell
cargo run --release --example embodied_lab -- --output target/embodied-v1.json
cargo test --all-targets --release
```

默认命令还会更新 Web 使用的 `app/public/embodied-v1.json`。模拟完全确定，训练和评估均不依赖界面。

## 协议

- 世界：15×15，7 份食物，14 个危险格；
- 生命：初始能量 28，上限 40；等待、移动、撞墙和危险均消耗能量；
- 感觉：12 通道，包括能量、当前位置食物、相对食物方向、前方边界、相对危险方向和最近后果；
- 内部：24 个带泄漏连续状态和适应变量的单元；
- 动作：前进、左转、右转、进食；
- 学习：内部状态到动作层的 96 个突触使用奖励调制资格迹；
- 训练：1200 张确定性训练地图；
- 测试：80 张种子不重叠的未见地图，评估期间关闭学习；
- 行为上限：每回合 240 步。

后果由能量变化和接近最近食物的微弱距离塑形组成。距离塑形是 v1 的工程脚手架，不是生物学主张，后续必须做移除对照。

## 结果

| 条件 | 平均食物 / 7 | 完成率 | 最终能量 | 平均存活步数 | 危险接触 |
|---|---:|---:|---:|---:|---:|
| 未经训练 | 0.500 | 0% | 3.416 | 192.9 | 11.8 |
| 关闭学习 | 0.500 | 0% | 3.416 | 192.9 | 11.8 |
| 学习后 | 7.000 | 100% | 39.585 | 131.5 | 4.7 |
| 打乱已学习突触 | 0.000 | 0% | 8.431 | 237.0 | 0.6 |
| 消融 6 个重要内部单元 | 0.350 | 0% | 8.058 | 197.5 | 7.8 |

全部 96 个动作突触发生持久变化，权重变化 RMS 为 1.064。学习后较短的平均步数是正面结果：主体在能量耗尽前更快收集完全部食物，回合因此提前结束。

## 验收

- [x] 权重产生持久变化；
- [x] 学习后在未见地图中胜过关闭学习；
- [x] 打乱已学习连接后行为退化；
- [x] 内部单元消融后行为退化；
- [x] 相同配置和种子产生相同完整结果；
- [x] 输出是实际动作和环境后果，不由外部分类器解释。

## 限制

- 控制器是连续状态神经启发模型，不是生物精确神经元；
- 食物方向感觉近似“气味梯度”，目前没有噪声和遮挡；
- 距离塑形让导航容易学习；
- 危险只造成能量损失，没有复杂触觉或疼痛系统；
- 单一需要和单一主体不能支持关于生命、意识或人类智能的结论。

v1 的价值是建立可观察、可证伪的闭环，而不是宣称已经创造生命。
