# Gate C v1.3：延迟能量与资格迹

## 结论

Gate C 通过全部冻结验收。在当前线索可见、控制器无状态、真实能量延迟 8 步到账的任务中：

- `eligibility_decay = 0.88` 达到 `99.3% [98.7%, 99.9%]`；
- `eligibility_decay = 0.00` 为 `47.0% [41.3%, 52.6%]`；
- 同种子配对增益为 `52.3 [46.5, 58.1]` 个百分点；
- 无资格迹从即时能量的 `99.9%` 降到延迟 8 步的 `47.0%`，配对下降 `52.9 [47.3, 58.5]` 个百分点；
- 延迟 4、资格迹 0.88 的随机线索对照为 `49.8% [48.5%, 51.0%]`。

因此，资格迹在这个受控任务中确实把延迟后果归因给了较早的岔路动作。它证明一个具体机制的功能，不证明系统已经能处理开放环境中的一般长期信用分配。

## 冻结协议

- 任务：`delayed-energy-fork/v1`；
- 当前可见线索直接指出左右目标，提交分支后线索关闭；
- 强制等待期的动作仍输出，但不改变进程；
- 正确分支的真实食物能量在等待结束时一次到账，错误分支没有到账；
- 奖励严格等于真实能量变化除以食物能量，没有塑形和正确答案标签；
- 无状态控制器，12 个感觉、24 个固定随机特征和 96 条可训练动作连接；
- 资格迹衰减 `0 / 0.50 / 0.88 / 0.97` × 能量延迟 `0 / 2 / 4 / 8`；
- 12 个未参与机制选择的正式模型种子，每格训练 1,200 回合、测试 200 回合；
- 开发种子 `0x474154455f430101` 用于冻结实现，正式种子 `0x474154455f430201` 只运行冻结协议。

## 4×4 结果矩阵

单元格为未见测试序列的正确分支比例。

| 能量延迟 | trace 0.00 | trace 0.50 | trace 0.88 | trace 0.97 |
|---:|---:|---:|---:|---:|
| 0 | 99.9% | 99.9% | 99.9% | 99.9% |
| 2 | 51.8% | 99.3% | 100.0% | 100.0% |
| 4 | 48.9% | 95.4% | 100.0% | 100.0% |
| 8 | 47.0% | 53.3% | 99.3% | 99.8% |

即时能量下四种条件都能学习左右映射，排除了 `trace = 0` 本身无法训练的解释。随着延迟增加，有效资格迹必须覆盖更长时间：0.50 在 4 步仍有效，到 8 步已经接近机会水平；0.88 和 0.97 覆盖到 8 步。

## 因果与防泄漏检查

| 检查 | 结果 |
|---|---|
| 延迟 8：0.88 − 0.00 | +52.3 pp，95% CI [46.5, 58.1] pp |
| trace 0：即时 − 延迟 8 | +52.9 pp，95% CI [47.3, 58.5] pp |
| 随机线索，延迟 4 / trace 0.88 | 49.8%，95% CI [48.5%, 51.0%] |
| 延迟 8 / trace 0.88 左目标 | 98.8% |
| 延迟 8 / trace 0.88 右目标 | 99.8% |
| 延迟 8 / trace 0.88 分支提交率 | 100% |

代表轨迹还检查了时间顺序：岔路动作提交后线索立即消失，随后恰好经历 8 个等待步骤；只有正确分支在最后一步出现真实能量增量。等待期没有目标、选择结果或正确性传感器，无状态控制器也不能把等待状态当作线索记忆。

## 样本效率

- 即时能量四种条件均为 12/12 个种子达到 75% 滑动窗口正确率，平均约 47～50 回合；
- 延迟 8、trace 0.88 为 12/12，平均约 83 回合；
- 延迟 8、trace 0.97 为 12/12，平均约 60 回合；
- 延迟 8、trace 0 只有 1/12 偶然达到阈值，跨种子表现仍为机会水平。

近乎 100% 的数字来自任务被有意简化为单个可见线索、单次分支动作和受控延迟。这个设计适合回答资格迹是否有用，不适合拿来代表复杂导航能力。

## 可重复性

```powershell
cargo run --release --example gate_c_lab
cargo test --test gate_c --release
```

权威快照为 `app/public/gate-c-v1.3.json`。测试覆盖完整结果确定性、等预算、等待步数、线索关闭和真实能量守恒。一次正式运行在当前开发机约为 `0.43 s`；该墙钟时间不进入确定性数据。

## 证据边界与下一步

Gate C 证明了动作读出连接上的奖励调制资格迹能够跨受控延迟分配责任。它仍没有证明：

- 多个先后动作之间能正确区分责任；
- 内部表示、资格迹时间常数或输入编码能够自行学习；
- 稀疏奖励导航中的探索与信用分配已经同时解决；
- 连续状态、循环网络或脉冲动力学在该机制上有额外收益。

下一步进入 Gate D，只增加可关闭的稀疏内部循环连接，并用 Gate B 记忆任务检验收益与稳定性；Gate C 保留为信用分配回归基准。
