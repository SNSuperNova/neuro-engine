# Map 0 v0.1：稳定可学习性地图

## 状态

已完成。权威版本：`learnability-map/v0.1`。

## 运行规模

| 阶段 | 配置 | 系统种子 | 运行数 |
|---|---:|---:|---:|
| 开发扫描 | 64 | 8 | 512 |
| 独立确认 | 6 | 12 | 72 |
| 因果对照 | 6 × 5 对照 | 12 | 360 |

全部结果数值有限，开发种子与确认种子不重叠，重复运行逐字段一致。正式命令：

```powershell
cargo run --release --example map0_lab
```

## 主要结果

开发扫描的最佳配置是 55：8 个种子中有 2 个同时通过全部条件，形成概率 25%，平均探针得分 56.2%。该结果只用于选择确认区域，不作为结论。

独立确认的 6 个配置为 `3, 23, 57, 55, 15, 7`。最佳仍是配置 55，但 12 个确认种子中没有一个通过完整形成标准：形成概率 `0%`，Wilson 95% 区间 `[0%, 24.2%]`。所有确认配置均为 0%，因此没有满足“至少 3 个相邻点、每点形成概率不低于 50%”的连续区域。

72 个确认系统中：

| 分类 | 数量 |
|---|---:|
| 稳定可学习 | 0 |
| 任务特化 | 71 |
| 僵硬 | 0 |
| 不稳定 | 1 |

这不是“完全学不会”。多数系统能完成一部分任务，但同一系统不能稳定地把能力组合起来。

## 探针边界

| 条件 | 通过数 / 72 | 比例 |
|---|---:|---:|
| 8 步短期记忆 | 72 | 100% |
| 6 步延迟信用 | 31 | 43% |
| 首次规则反转 | 24 | 33% |
| 恢复原规则 | 72 | 100% |
| 重复反转最终正确率 | 21 | 29% |
| 第二次反转不慢于第一次 | 22 | 31% |
| 重要单元失活造成足够损伤 | 27 | 38% |
| 扰动后恢复至少 10 个百分点 | 11 | 15% |

原规则恢复 100% 与动作读出仍保存原映射有关，不能单独证明形成了可泛化的记忆巩固。真正的瓶颈集中在延迟后的内部更新、反复切换和损伤后的重组。

## 因果对照

确认配置的完整形成概率已经处于零地板，因此对照无法进一步降低它。平均探针得分仍显示清晰退化：

| 对照 | 相对基线的平均探针得分变化 |
|---|---:|
| 随机后果 | -29 个百分点 |
| 冻结内部可塑性 | -18 个百分点 |
| 关闭探索 | -14 个百分点 |
| 置乱循环结构 | -7 个百分点 |
| 关闭内稳态 | +6 个百分点 |

随机后果在单个配置上的最大下降为 38.9 个百分点，超过冻结的 10 点因果阈值。说明当前部分能力确实依赖有意义的后果信号、内部可塑性和探索，而不是纯随机命中。

关闭内稳态提高了部分短期任务分数，但 72/72 个关闭内稳态运行都被判为不稳定：开放权重组平均相对漂移约 10.79，最大 26.58。这个结果把 Gate F 的“内稳态只控制参数尺度”推进了一步：它可能牺牲短期适应速度来换取权重有界，但当前形式仍未实现稳定与学习的兼得。

## 结论

Map 0 协议完整通过，但科学假设的当前实现版本没有通过：在扫描范围内，没有证据支持存在连续、跨种子可重复的稳定可学习区域。

当前最重要的结论不是节点数量不足，而是已有 24 单元底层在多项能力组合时出现明显机制冲突：

- 较强更新有利于短期反转，却加剧覆盖和漂移；
- 内稳态压住漂移，但可能限制重新组织；
- 原读出保存旧映射使“恢复”容易，却没有带来可靠的重复切换；
- 损伤恢复是最弱探针，说明当前固定结构和仅 48 个开放循环槽位缺乏重组余量。

按照冻结路线，下一步不能直接进入 Gate G，也不应先扩大节点数。应只修改一个微观机制后重绘局部地图。首选候选是把“每步强制拉回参考范数”的内稳态改为较慢的活动/权重双时间尺度调节，并保持其他规则与 Map 0 探针不变。
