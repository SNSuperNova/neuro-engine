# Phase 2 / P2-0：最小模式输入切片

- 日期：2026-08-18
- 状态：工程切片已实现，尚未达到功能群或读出结论
- 网络：`experiment-001/v1` 的固定 100 神经元拓扑

## 目的

验证无需先完成通用 Gate 4，也能从相同网络条件生成一组成对试验：

```text
持续起搏 + 空白 3×3 输入
持续起搏 + 中心十字 3×3 输入
```

两次运行共享拓扑、初始状态、起搏时间线和运行种子，唯一差异是有记录的图形输入事件。

## 输入映射

- 九个输入通道固定映射到神经元 `4`～`12`；
- 起搏神经元为 `0`～`3`，不与输入通道重叠；
- 中心十字激活 5 个通道；
- 输入不是强制放电，而是在 `900～1300 ms` 之间注入有界兴奋事件；
- 冻结试跑参数：每个激活通道每 `30 ms` 输入 `10 mV`，共 70 个输入事件；
- 回放包含空白和中心十字分支，并标明输入图形、通道和刺激时间窗。

## 输入扫描

首次试跑发现响应对输入间隔存在明显非线性，不能简单认为“越弱越稳定”。例如 `4 mV / 30 ms` 出现高放电状态，而相邻配置没有同等现象。因此保留 `phase2_scan` 命令，并选择满足现有工程稳定边界且响应差异较清晰的 `10 mV / 30 ms` 作为 P2-0 参数。

```text
pattern.mean_firing_rate_hz             7.475
pattern.active_neuron_fraction          0.570
pattern.synchronous_burst_bin_fraction  0.075
trajectory.mean_rms_spike_difference    0.414
trajectory.changed_bin_fraction         0.914
```

这些数值只说明本次持续输入没有明显破坏 `experiment-001/v1` 的工程活动范围，并且相对于空白对照产生了可测差异。它们不能证明网络识别了十字、形成了功能群或具有泛化能力。

## 已验证

- 图形编码只向激活格对应的神经元发送事件；
- 输入事件严格位于有界刺激窗口；
- 成对试验可确定性重放；
- 空白分支不包含图形刺激事件；
- 图形分支的刺激事件数量与编码一致；
- 3D、二维状态平面、输入面板、时间轴和对照差异来自同一回放包；
- 浏览器验收中首次分歧发生于输入开始的 `900 ms`，100 神经元场景保持约 150 FPS 以上。
