# 离线结构证据诊断：反事实换边结果

## 结论

诊断协议完整通过，正式决策为 `CounterfactualEffectsFlat`。在冻结的一边替换自由度和 32 试次前向窗口内，所有合法候选中最好的 oracle 换边平均只提高 `1.38 pp [1.16, 1.61]`，低于预注册的 `2 pp` 可用性门槛。当前 M2C 失败首先受限于“可执行的一边替换在这个时间尺度上作用太小”，不能先归因于在线选择公式写得不够复杂。

局部证据与反事实收益存在很弱的正相关：Spearman `0.046 [0.029, 0.062]`，打乱排名为 `0.002 [-0.000, 0.005]`，差为 `0.044 [0.027, 0.060]`。但该差异没有达到预注册的 `0.10` 信息强度。证据首选换边的平均收益为 `+0.08 pp [-0.15, 0.31]`，随机候选期望为 `-0.12 pp [-0.25, 0.01]`，两者差 `+0.20 pp [0.06, 0.33]`；虽可重复大于零，但远低于预注册的 `1 pp` 实用门槛。

## 冻结诊断协议

- 使用 M2C 已淘汰候选 P3 的原始局部证据：重连间隔 64，证据 EMA 衰减 `0.80`；
- 主连续流仍为 `A → B → C → D → A`，只运行原有权重可塑性，不发生任何在线结构写入；
- 覆盖从第 64 到第 1152 试次的全部 18 个实际重连机会，而不是只抽取部分阶段；
- 每个检查点只诊断当时轮到的目标单元，并固定替换局部证据较弱的现有槽位；
- 枚举全部 17 个合法非活动来源；每个候选继承被替换边的同一个权重；
- 无换边基线和所有候选都从同一控制器状态克隆，经历相同的 32 个训练试次、符号序列、探索随机数和 48 个无探索探针；
- 反事实收益定义为候选换边的前向准确率减去无换边克隆的前向准确率；
- 局部证据只负责排序。目标规则和准确率只在候选选择完成后供离线评估器计算收益，不反馈给主流或调整机制；
- 每个检查点生成 16 个证据打乱排名对照；统计先在每个“载体参数 × 种子”的 18 个检查点内聚合，再对独立运行计算区间。

开发阶段包含 24 个种子-载体运行、432 个检查点和 7344 个候选反事实；独立确认包含 48 个运行、864 个检查点和 14688 个候选反事实。开发和确认种子不重叠。

## 总体确认结果

| 指标 | 独立确认 |
|---|---:|
| 局部证据 Spearman | `0.046 [0.029, 0.062]` |
| 打乱排名 Spearman | `0.002 [-0.000, 0.005]` |
| 相关优势 | `0.044 [0.027, 0.060]` |
| 证据首选收益 | `+0.08 pp [-0.15, 0.31]` |
| 随机候选期望收益 | `-0.12 pp [-0.25, 0.01]` |
| 首选相对随机优势 | `+0.20 pp [0.06, 0.33]` |
| oracle 收益 | `+1.38 pp [1.16, 1.61]` |
| 证据首选遗憾 | `1.31 pp [1.04, 1.58]` |
| top-quartile 命中率 | `29.7% [25.3%, 34.2%]` |
| 17 候选下机会命中率 | `29.4%` |

所有输出有限，主流前后拓扑摘要逐位相同，动作读出摘要逐位相同。每个检查点均枚举 17 个合法候选，没有把反事实克隆状态写回主流。

| 阶段 | 规则 | Spearman | 首选收益 | 随机收益 | oracle 收益 | top-quartile 命中 |

| 4 | D | `0.014` | `-0.08 pp` | `-0.20 pp` | `+0.53 pp` | `30.7%` |
| 5 | A 回归 | `0.155 [0.111, 0.199]` | `+1.03 pp [0.20, 1.86]` | `0.00 pp` | `+2.46 pp` | `34.0% [26.3%, 41.8%]` |

A 回归阶段是唯一显示较明确结构信息的局部条件：证据相关和首选收益均为正。top-quartile 命中为 `34.0% [26.3%, 41.8%]`，区间仍覆盖 `29.4%` 机会水平。它是预注册分层结果，不能替代总体确认结论；B/C/D 的结构信号接近零。这更像“已有历史恢复时出现一点结构信号”，不是支持一般新规则容量的证据。

## 机制解释与下一步

当前证据支持以下顺序：

1. 在 32 试次窗口中，一次单边迁移的最佳可用作用总体很小；
2. 局部资格证据含有可重复但很弱的排序信息；首选相对随机只有 `+0.20 pp`，统计为正但没有实用强度；
3. 微弱信息集中于 A 回归，可能依赖已有历史，而不是形成新规则表示；
4. 因此不应直接设计第二个更复杂的在线重连公式，也不能进入 M3。

该建议现已由 [structural-timescale-v0.5.md](structural-timescale-v0.5.md) 执行：固定同一批克隆状态和候选比较 `[0, 32, 128, 256]` 后，长期 oracle 没有增长，正式定位为单边替换自由度不足。测试没有增加节点、连接预算或在线机制。
